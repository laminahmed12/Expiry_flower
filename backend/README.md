# منظومة الخادم البرمجي (Backend) - ExpiryGuard API

الواجهة الخلفية لنظام إدارة ومتابعة تواريخ الصلاحية مبنية باستخدام **Python & FastAPI & SQLAlchemy**.

## المميزات البرمجية المنفذة:
1. **قاعدة البيانات**:
   - جدول المواد: (اسم المادة، التصنيف الأساسي [أغذية، استهلاكية، أدوية]، تاريخ الإنتاج، تاريخ الانتهاء، الكمية، مكان التخزين، مسار صورة المنتج، الباركود).
2. **التنبيه الصوتي (Audio & Text-to-Speech)**:
   - فحص المواد واستخراج نصوص التنبيهات المنطوقة مع تخصيص صفارة إنذار للأدوية والمواد الحساسة.
3. **النسخ الاحتياطي (Backup & Restore)**:
   - مسار `/api/backup/export` لتصدير البيانات بصيغة JSON آمنة.
   - مسار `/api/backup/import` لاستيراد النسخ الاحتياطية وإعادتها لقاعدة البيانات.
4. **نظام التراخيص والفترة التجريبية**:
   - فترة تجريبية 10 أيام تلقائياً للمستخدمين الجدد.
   - رموز تفعيل بمدد (6 أشهر، سنة، أو دائم).
5. **لوحة تحكم Adreemk المخفية**:
   - محمية بالرمز السري `116936`.
   - توليد رموز تفعيل جديدة مع تحديد المدة.
   - استعراض كل الرموز وإيقاف/إلغاء تفعيل أي رمز بضغطة زر.

## طريقة التشغيل:
```bash
cd backend
pip install -r requirements.txt
python app.py
```
سيعمل الخادم على الرابط: `http://localhost:8000`
ويمكن معاينة وتجربة جميع الـ Endpoints عبر التوثيق التفاعلي:
`http://localhost:8000/docs`
